# 🎮 AI Phonics Block Adventure

A Minecraft-style phonics game for primary school students (K2–K3, ages 5–7), powered by **Qwen AI** (natural TTS voice + adaptive questions). Deployed on **Cloudflare Workers**.

## Features

- 🧱 Minecraft-style 3D environment built with Three.js
- 🔊 Natural voice pronunciation via **Qwen CosyVoice TTS**
- 🤖 Adaptive questions generated by **Qwen Plus** — harder after correct answers, focuses on weak letters
- 🎯 Crosshair aim + SPACE to smash blocks (keyboard)
- 👆 Tap-to-select for tablets/touch screens
- 🔥 Streak counter with bonus encouragement
- ⌨️ Also accepts direct letter key presses
- Graceful fallback to browser TTS when API is unavailable

## Project Structure


## Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Set your Qwen API key as a Cloudflare secret

Get your key from [DashScope International](https://dashscope-intl.aliyuncs.com/).

```bash
npx wrangler secret put QWEN_API_KEY
# Enter your key at the prompt
```

### 3. Local development

```bash
npm run dev
# Opens at http://localhost:8787
```

### 4. Deploy to Cloudflare

```bash
npm run deploy
```

## Qwen APIs used

| Feature           | Model / Endpoint                                                                 |
|-------------------|----------------------------------------------------------------------------------|
| TTS voice         | `cosyvoice-v1` · voice `Cherry` · `/compatible-mode/v1/audio/speech`             |
| Question generation | `qwen-plus` · `/compatible-mode/v1/chat/completions`                           |

Both are proxied through the Cloudflare Worker — the API key never reaches the browser.

## How to play

| Action | Control |
|--------|---------|
| Walk   | Arrow keys ↑ ↓ ← → |
| Smash aimed block | SPACE |
| Select letter | Press the letter key, or tap/click the block |

Listen to the AI teacher, find the matching letter block, and smash it! 🎉
